- Emotional neutrality, cognitive clarity
- Daily: breath + silence + 1 strategic focus
- Protocol: Pause → Observe → Respond (not react)
- **Lyra mapping**: Daily Protocol, Focus Score, Anti-Noise

### Level 2 — Strategic INTJ (War Mode)
- Define daily: 1 strategic move + 1 thing to ignore
- Build leverage, not tasks
- **Lyra mapping**: Today Focus (3-max), Emperor Time, Strategic Direction

### Level 3 — Architect of Power
- Control flows: Information, Capital, Distribution, Execution
- Power Stack: Signal → Decision → Execution → Distribution engines

- **Lyra mapping**: Dashboard metrics, Goals, Knowledge Engine

- Control systems, not outcomes. Be invisible but essential.
- Control points: Infra, Protocol, Capital, Access
- Empire metrics: flow volume, dependency, switching cost, adoption
- **Lyra mapping**: Future vision — agent orchestration, data graph
