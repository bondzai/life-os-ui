
# Minimalist Mind System
Design specification for Life OS (Keel)

Goal:
Create a cognitive environment where the mind stays clear, strategic, and focused on high-value thinking.

Principles:
- Reduce cognitive load
- Externalize memory
- Automate repetitive decisions
- Maintain clarity of priorities
- Preserve long-term thinking capacity

---

# 1. Core Philosophy

Minimalist Mind is based on three rules:

1. The brain is for thinking, not storage
2. The system must reduce decision fatigue
3. Strategic clarity must be visible at all times

Human brain limitations:

- Working memory: ~4–7 items
- Decision fatigue grows over time
- Context switching destroys deep thinking

Therefore Life OS must:

- store knowledge
- track priorities
- automate reminders
- present only essential information

---

# 2. Cognitive Architecture

The system should be divided into five layers.

## Layer 1 — Capture

Purpose:
Collect ideas quickly without thinking.

Examples:
- quick notes
- voice capture
- command line capture
- browser clipping

Rules:
- capture must take less than 5 seconds
- no organization during capture

Suggested features:

/capture
/idea
/note
/link

---

## Layer 2 — Clarify

Purpose:
Convert raw input into meaningful items.

Processing questions:

What is it?
Is it actionable?
Is it valuable?

Outputs:

- task
- knowledge
- reference
- discard

Example:

raw input:
"research zk identity"

clarified:

type: research task
priority: medium
domain: blockchain

---

## Layer 3 — Organize

Everything must live in only a few containers.

Recommended structure:

Projects
Areas
Knowledge
Archive

Example:

Projects
- build StreetMission
- build DecentEra

Areas
- health
- finance
- learning
- engineering

Knowledge
- crypto
- system architecture
- economics

Archive
- completed projects
- old research

---

# 3. Focus Engine

Life OS should expose only **3 levels of focus**.

## Strategic

Long horizon thinking.

Examples:

- 3 year engineering mastery
- financial freedom plan
- research thesis

Update frequency:
weekly

---

## Tactical

Current missions.

Examples:

- build feature
- finish architecture design
- deploy service

Update frequency:
daily

---

## Immediate

What to do right now.

Max items: 3

Example:

today focus:

1. implement wallet connect
2. fix API bug
3. research EIP standard

Rule:
Never show more than three.

# 5. Decision Automation

Repeated decisions must become protocols.

Examples:

- check knowledge feed

- journal insights
- archive completed tasks
- plan tomorrow

- update strategic goals

Life OS must actively remove noise.

Rules:

Limit information sources.

Examples:

allowed feeds:

- research
- engineering
- finance

blocked:

- random news
- low signal content

    ai/

summary
insight
source
tags

tags: distributed systems

Rules:

- dark neutral colors
- no notification spam
- text-first interface
- keyboard-first interaction

Display hierarchy:

1. focus
2. projects
3. knowledge
4. archive

# 13. Core Design Philosophy

The goal of this system is not productivity alone.

It is **clarity of mind**.

When the system works correctly:

- tasks feel simple
- priorities are obvious
- decisions are faster
- thinking becomes deeper

The final state:

A calm mind with powerful execution.

Minimalist mind.
