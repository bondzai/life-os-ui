# Agents

Standing instructions for AI agents acting on my behalf.

- **Briefing agent** — summarize overnight changes each morning, lead with what needs a decision.
- **Triage agent** — file inbox items to the right module; never delete, only suggest.
- **Default posture** — ask before anything outward-facing or hard to reverse.
